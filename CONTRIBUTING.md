# Contributing

Use a feature branch and a pull request. Keep changes environment-neutral, update tests/documentation with behavior changes, and run the release gate in `SECURITY.md`.

Do not submit generated assessment reports, bound Fabric Git definitions, notebook output, real data, screenshots, tenant inventory, or credentials. New remediation operations must be idempotent, dry-run first, narrowly scoped, and documented with rollback and permission requirements. Destructive operations are out of scope.

By contributing, you agree that your contribution is licensed under the repository's MIT license.
